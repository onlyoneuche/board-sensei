# Instrument assets

Board Sensei looks here first for `BoardSensei.sf2`, then `Piano.sf2`, before
falling back to macOS's General MIDI DLS bank.

Use a GM-compatible, multi-sampled SoundFont whose license permits bundling and
commercial redistribution. Retain its license and attribution next to the asset,
and audition every program exposed by `PracticeInstrument` before release.

Do not commit an unlicensed or personal Logic Pro sound-library export. Logic's
factory instruments and samples are not redistributable application assets.
